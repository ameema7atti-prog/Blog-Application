# Real-Time Chat Application 💬

A full-stack real-time chat application built using the MERN stack and Socket.io for **Project 3** of **Task 4** in the **Syntecxhub Web Development Internship**. This application allows users to join chat rooms, exchange real-time messages, and view past conversation histories.

## 🚀 Features
* **Real-Time Messaging:** Powered by Socket.io for instant, bidirectional communication between clients.
* **Chat Rooms:** Allows users to join different rooms and send targeted messages.
* **Message History:** Persistently stores all chat history in MongoDB so previous conversations are retained.
* **Production Ready:** Designed for seamless deployment and live usage.

## 🛠️ Tech Stack
* **Frontend:** React.js, HTML5, CSS3
* **Backend:** Node.js, Express.js, Socket.io
* **Database:** MongoDB
